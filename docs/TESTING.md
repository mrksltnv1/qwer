## Найденные и исправленные дефекты (по результатам живых тестов)

| Дефект | Как найден | Исправление |
| --- | --- | --- |
| `kotlin.Result.Success` — внутренний API | компиляция | `result.isSuccess` |
| Парсер видел только первого пира | упавший тест `multiple peers are counted` | `peerBlocks()` собирает все `[Peer]` |
| Ожидания окна отказа были неверны | 4 упавших теста | окно отсчитывается от первой наблюдённой неудачи; тесты переписаны |
| Застой трафика недостижим при 90 с | упавший тест | в тесте короткий порог |
| **Проба растягивалась до 27 с** | живой тест: метки 10:08:31 → 10:08:58 | дедлайн на цель |
| **Проба всё ещё растягивалась до 13.5 с** | живой тест: 10:11:17 → 10:11:31 | общий бюджет на всю пробу, цели параллельно |

Последние два дефекта видны **только** на реальном отказе сети — юнит-тесты с
фейковой пробой их не ловят, потому что там проба возвращается мгновенно.

## Что НЕ тестировалось

| Сценарий | Причина |
| --- | --- |
| Смена Wi-Fi ↔ LTE | тестовая цель — виртуалка на QEMU, реального радио нет |
| Doze / убийство процесса системой | требует длительного прогона на физическом устройстве |
| Перезагрузка устройства | не проверялось |
| AmneziaWG с реальной обфускацией | нет AWG-сервера; проверен только парсинг классификации |
| Импорт по `myvpn://import` end-to-end | нет сервера выдачи конфигурации |
| WDTT Plus подключение | приложение не установлено на тестовой VM |
