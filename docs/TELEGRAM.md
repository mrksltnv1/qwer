# Интеграция с Telegram

## Ссылка для добавления конфигурации

```
myvpn://import?token=<opaque_token>
```

### Что валидируется (и покрыто тестами)

| Проверка | Правило | Тест |
| --- | --- | --- |
| Схема | строго `myvpn`, иначе `NotOurs` | `foreign scheme is not ours` |
| Хост | строго `import` (регистр не важен) | `foreign host is rejected` |
| Токен присутствует | иначе `Rejected` | `missing token is rejected` |
| Длина токена | 16…512 символов | `too short token is rejected` |
| Алфавит токена | `[A-Za-z0-9._-]` | `token with illegal characters is rejected` |

### Чего НЕ происходит

- **Приватный ключ или полный конфиг в URL не передаётся.** В ссылке только
  непрозрачный токен.
- **Туннель не стартует сам** по факту открытия ссылки. Ссылка даёт только
  `ImportRequest`, который пользователь подтверждает в UI.
- **Токен не логируется.** В диагностику попадает лишь необратимый hint —
  первые 4 байта SHA-256 (`DeepLinkHandler.hint`), чтобы поддержка могла
  сопоставить ссылку, не зная сам токен.

### Одноразовость и срок жизни

Требуются на стороне сервера: токен одноразовый, с TTL. **Сервер пока не
реализован**, поэтому сейчас ссылка валидируется, но конфиг не загружается —
UI говорит об этом прямо, а не имитирует успех.

## Ссылка на приложение

```
https://<домен>/download   → APK по HTTPS
```

Пока релиз не опубликован, используется локальный/тестовый URL. **Несуществующие
адреса в боте не выдумываем.**

## App Links

Custom scheme `myvpn://` работает без домена и уже подключён в манифесте.
Verified App Links требуют собственного домена и `assetlinks.json`; поле
`BuildConfig.APP_LINK_HOST` заведено пустым — заполняется при появлении домена.

## Что должен уметь бот

1. Выдать ссылку на скачивание APK (HTTPS).
2. Выдать `myvpn://import?token=...` по запросу пользователя.
3. Токен — одноразовый, TTL (например, 15 минут), привязан к Telegram user id.

## Почему WDTT-ссылки не переиспользуются

WDTT Plus объявляет свои схемы (`wdtt://`, `https://<домен>/c/`) и свой формат
передачи профиля. Это не публичный API, а внутренний формат другого приложения.
Свой конфиг в него подсовывать нельзя — только открыть WDTT Plus и дать
пользователю штатный путь внутри него.
