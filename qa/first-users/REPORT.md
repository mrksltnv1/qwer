# QA первых пользователей

## Критерий первого успешного действия

> Пользователь открыл ссылку из Telegram → приложение импортировало профиль →
> выдал системное разрешение VPN → туннель реально поднялся → приложение
> подтвердило доступ в сеть **через туннель** (проверкой, а не флагом).

## Статус: БРАУЗЕРНАЯ ЧАСТЬ ЗАБЛОКИРОВАНА

Браузерный MCP в окружении OpenClaw **отсутствует**. Проверено:

```
openclaw mcp list  →  только "umbrel"
tool_search        →  web_fetch (без навигации/кликов), umbrel__control_machine
openclaw browser doctor → FAIL: browser not running; инструмент не спроецирован
```

Поэтому четыре сценария (нетерпеливый, скептик, мобильный 375px/3G, тестер на
прочность) **не выполнялись**. Никаких вымышленных результатов ниже нет.

### Команда установки (OpenClaw 2026.9.8)

```bash
openclaw mcp add playwright --command npx --arg -y --arg @playwright/mcp@latest
openclaw mcp doctor playwright --probe
```

⚠️ Ограничения этого окружения:
- OpenClaw в Docker **не рекомендует** `npx playwright` (конфликт npm-override);
- контейнер aarch64 — Chromium под arm64 ставится отдельно.

Более надёжно: поднять Playwright MCP на x86_64-хосте (например, сборочный
LXC 110) и подключить как удалённый сервер.

Официальная документация: `docs/tools/browser-control.md`,
`docs/cli/mcp/registry.md`.

## Что вместо браузерного QA сделано

Проверен **нативный** пользовательский путь на реальном Android (BlissOS 13),
потому что продукт — Android-приложение, а не сайт. Метрики:

| Метрика | Значение |
| --- | --- |
| Нажатий до первого успешного подключения | **2** (импорт конфига → «Подключить») + системный диалог VPN |
| Время до подтверждённого подключения | ~4 с от нажатия до `PROBE_RESULT ok=true` |
| Подтверждение успеха | handshake на сервере, а не текст в UI |
| Причина отказа (тест без WDTT) | «WDTT Plus не установлен: переключение невозможно» |

## Что должен проверить браузерный QA, когда MCP появится

1. Страница загрузки: виден ли APK и инструкция по установке вне Google Play.
2. Deep link `qwer://import?token=…` открывается ли (нужен реальный домен/схема).
3. Ширина 375 px: не ломается ли вёрстка страницы (не приложения).
4. Повторные нажатия и возврат «назад» на странице загрузки.
