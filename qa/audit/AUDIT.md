# Комплексный аудит

**Важно:** аудит выполнен **мной, автором кода**, а не независимыми субагентами —
браузерный MCP недоступен, а отдельные аудиторы не запускались. Это снижает
независимость оценки, и я это не скрываю. Все статусы ниже опираются на
проверяемые артефакты (файл + строка, лог, тест), а не на «выглядит нормально».

## 1. Дизайн и производительность

| Пункт | Статус | Доказательство |
| --- | --- | --- |
| Единая дизайн-система | ✅ | `ui/Theme.kt`: одна схема, `StateColors` для всех состояний |
| Отдельные состояния: загрузка/пусто/ошибка/успех | ✅ | `MainScreen`: `progpermille`-спиннер только в `isBusy`, `Failed` → «Повторить», `profiles.isEmpty()` → текст-подсказка |
| Поддержка мобильных экранов | ✅ | `verticalScroll`, `fillMaxWidth`, tap-target кнопки 56 dp |
| Доступность | ⚠️ частично | `contentDescription` на кнопке подключения и на удалении профиля; **не проверено** со скринридером TalkBack |
| Блокировка UI-потока | ✅ | вся работа с движком и сетью в `Dispatchers.IO`; UI-поток только рендер |
| Списки > 1000 записей | ➖ неприменимо | профилей в UI единицы; `LazyColumn` не используется осознанно |
| Оптимизация изображений (WebP/AVIF) | ➖ неприменимо | растровой графики нет, только векторные иконки |
| Отложенная загрузка ниже первого экрана | ➖ неприменимо | один экран, контент помещается |
| Мониторинг ошибок/производительности | ⚠️ | структурные события в logcat есть; внешней аналитики **нет** (сознательно: меньше утечек) |
| Размер APK | ⚠️ | 30 МБ из-за 4 ABI native-движка; можно урезать `abiFilters` (см. BUILD.md) |
| Время холодного старта | ➖ не измерено | нужен `am start -W` на устройстве; не выполнялось |

## 2. Безопасность

| Пункт | Статус | Доказательство |
| --- | --- | --- |
| Приватные ключи не в публичных файлах/APK/логах | ✅ | `adb logcat` за весь прогон: 0 совпадений по regex ключа и по конкретному ключу |
| Секреты не в истории Git | ✅ | проект не публиковался; `.gitignore` покрывает `local.properties`, `*.keystore` |
| Ранее раскрытые секреты выявлены | ⚠️ **требуется твоё решение** | в этом проекте новых утечек нет; токены инфраструктуры (GitHub, Zabbix, SSH) лежат **открытым текстом в `AGENTS.md`** рабочего пространства — это существующая проблема окружения, не этого проекта |
| Серверный API проверяет authn/authz | ➖ **неприменимо** | серверного API нет |
| Доступ к чужим профилям запрещён | ✅ | профили локальные, на устройстве; сетевого слоя доступа нет |
| Валидация deep links | ✅ | 8 юнит-тестов, строгая схема+хост+алфавит токена |
| Валидация импорта конфигурации | ✅ | 11 юнит-тестов, лимит 64 КБ, запрет control-символов |

| Хранение локальных секретов | ✅ | AES-GCM + Android Keystore, non-exportable |
| Права Android и работа VpnService | ✅ | только INTERNET, ACCESS_NETWORK_STATE, FOREGROUND_SERVICE(_SPECIAL_USE), POST_NOTIFICATIONS; сервис движка `exported="false"` + `BIND_VPN_SERVICE` |

## Что требует твоего подтверждения

1. **Открытые токены в `AGENTS.md`** (GitHub, Zabbix, SSH-пароли, Cloudflare).
   Они вне этого проекта, но лежат plaintext. Рекомендую перенести в secret store
   и ротировать. Сам не ротировал: это затронет работающую инфраструктуру.
2. **Лицензия продукта**: Apache-2.0 (WDTT только handover) или GPLv3
   (встроенный WDTT-движок и бесшовный failover).
3. **`setUserAuthenticationRequired(false)`** в Keystore: выбран ради фонового
   автоподключения. Если нужна биометрия перед подключением — скажи, поменяю.
